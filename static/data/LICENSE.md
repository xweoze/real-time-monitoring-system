# 대한민국 시·도 경계 데이터

`skorea-provinces-2018-topo-simple.json`은 통계청 통계지리정보서비스
(SGIS)의 행정구역 경계 원자료를 `southkorea/southkorea-maps` 프로젝트가
TopoJSON으로 가공한 데이터입니다.

- 원자료: 통계청 통계지리정보서비스(SGIS)
- 자료 버전: 가공 저장소의 `kostat/2018` 시·도 경계
- 가공 저장소: https://github.com/southkorea/southkorea-maps
- 원본 파일: https://github.com/southkorea/southkorea-maps/blob/master/kostat/2018/json/skorea-provinces-2018-topo-simple.json

가공 저장소 README는 KOSTAT 자료를 공유·변형할 수 있다고 안내합니다. 실제
배포·재배포 또는 상업적 사용 전에는 SGIS의 최신 이용 조건과 출처 표기 요구사항을
다시 확인해야 합니다. 이 프로젝트의 지도에는 `통계청 SGIS (2018)` 출처를
표시합니다.
